# Goat Management System

A clean, professional goat record management dashboard built as a simple editable web app.

## Features
- Add goat records
- Edit existing records
- Delete goats from the system
- Track:
  - goat number
  - vaccination date
  - number of goats
  - date of birth
  - owner
- Search records by any field
- Live summary statistics
- Data saved in the browser using local storage

## Run locally
1. Open `index.html` in your browser, or
2. Serve it with a local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files
- `index.html` — user interface
- `styles.css` — professional dashboard styling
- `app.js` — record management and data logic

## Notes
This project is designed as a simple editable system and can be expanded later with a database, login system, PDF export, or API integration.
